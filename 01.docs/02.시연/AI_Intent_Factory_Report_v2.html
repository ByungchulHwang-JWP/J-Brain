11

탄소중립플랫폼 시연 시나리오

플랫폼 가동 및 업무 데이터 연동 정합성 검증을 위한 핵심 데모 워크플로우

JWINPARTNERS

STEP 01. Intent Factory 셋업 및 지식 입력

신규 챗봇 프로젝트(Tenant) 생성 및 탄소중립 업무 매뉴얼/규정 문서(PDF) 업로드 및 파싱 실행.

STEP 02. AI 도출 지식 리뷰 및 API Action 매핑

"시세 조회" 의도 인식 시 ➔ KAU 시세 라이브 API 연동 매핑.
"화면 이동" 의도 인식 시 ➔ 탄소 대시보드 URL 딥링크 매핑.

STEP 03. Pack 패키징 및 내부망 배포

자동 무결성 검증 후 지식 팩(.zip)을 빌드하여 사내 폐쇄망 Runtime Server에 무중단 Import 적용.

STEP 04. 챗봇 테스트 (Live Demo)

"오늘 배출권 시세 얼마야?", "사용자 인증 규정 알려줘" 질의를 통한 즉각적인 API 응답 및 매뉴얼 출처 확인 검증.
