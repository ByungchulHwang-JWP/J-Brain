Executive Summary

C-Level 요약 보고

당초 계획한 "생성형 LLM의 보안/비용/환각 문제를 해결하는 경량 NLU + Action 기반 공통 챗봇 플랫폼(J-Brain)"의 1차 MVP(C-lite) 개발을 성공적으로 완수하였습니다.

Achievement 1

분리형 아키텍처 검증

공통 플랫폼(엔진)과 도메인별 Intent Pack의 물리적/논리적 완벽 분리 구현. 내부망 보안 요건 100% 충족.

Achievement 2

탄소중립 파일럿 적용

KAU 시세 조회, 매뉴얼 검색, 업무 대시보드 이동 등 핵심 유즈케이스의 챗봇화 완벽 시연.

Achievement 3

전사 확산 파이프라인

코드 작성 없이 AI가 지식을 추출하고 팩을 빌드하는 "Intent Factory" 관리자 포털 UI/UX 완성.

추진 배경 및 문제점

기업 내부망 챗봇 도입의 3대 허들 극복

As-Is (Pain Points)

  • 보안 제약: 외부 LLM API(OpenAI 등) 연동 불가
  • 비용 부담: 자체 sLLM 구축 시 막대한 GPU 인프라/인건비 소모
  • 환각 리스크: 정교한 사내 규정을 왜곡하여 답변하는 할루시네이션 치명적
➔

To-Be (J-Brain Solution)

  • 하이브리드 아키텍처: 외부망(생성)과 내부망(실행) 분리
  • 경량화 엔진: LLM 의존도를 낮추고 자체 NLU 라우팅 엔진 활용
  • 근거 기반 답변: Intent Pack 기반 100% 통제 가능한 답변과 Action 연동

Intent Factory (Product Showcase)

코딩 없이 챗봇을 설계하는 No-Code 포털

🤖 AI 의도 자동 추출 (Intent Discovery)

업로드된 탄소중립 매뉴얼을 LangGraph 기반 AI 에이전트가 분석하여, 사용자가 물어볼 만한 '질문(의도)'과 '답변(FAQ)'을 자동으로 도출합니다.

🔗 Action 기반 매핑 (Action Connect)

특정 의도("배출권 시세 조회")에 대해 단순 텍스트 답변이 아닌, 사내 API 호출(`query_card`) 또는 화면 이동(`navigation_card`) 액션을 UI에서 손쉽게 매핑합니다.

📦 원클릭 Pack 빌드 (Pack Validation)

설계된 인텐트들의 충돌 여부, 필수 엔티티 누락 등을 자동 검증한 뒤, 하나의 독립적인 버전(v0.1.0) 압축 파일로 패키징합니다.

Runtime & Deploy

초경량 / 초고속 내부망 챗봇 엔진 런타임

구분 런타임(Runtime) 환경 특장점
NLU 매칭 속도 무거운 LLM 추론 없이, Vector Similarity Search를 통한 ms(밀리초) 단위의 초고속 의도 매칭
Zero-Hallucination 생성형 답변을 배제하고, 사전 정의된 FAQ나 Action 템플릿만 출력하여 100% 신뢰성 보장
Seamless Update 서버 재시작 없이 새로운 Intent Pack Zip 파일만 업로드(Import)하면 실시간으로 챗봇 지능 갱신

Runtime QA 도구

블랙박스를 투명하게: 챗봇이 왜 이런 답변을 했는지 Confidence Score(신뢰도 점수)와 매칭된 Intent 내역을 실시간으로 디버깅할 수 있는 관리자 화면 제공.

의도 검증 후 v0.1.0 팩을 생성(Zip)하여 Runtime 서버에 Import.

"탄소 현황 띄워줘"(화면이동) / "규정 알려줘"(FAQ) / "배출권 시세 얼마야"(API 연동) 질의 검증.
