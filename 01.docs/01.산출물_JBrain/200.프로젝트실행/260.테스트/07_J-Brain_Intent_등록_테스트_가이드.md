# 📘 J-Brain 챗봇 Intent 등록 완벽 가이드 (초보자용)

본 가이드는 J-Brain 시스템을 처음 접하는 사용자도 챗봇의 "의도(Intent)"를 설계하고 "실행(Action)"을 연결하여 실제 채팅창에서 테스트해 볼 수 있도록 아주 상세하게 작성된 **High-End 테스트 매뉴얼**입니다.

---

## 🎯 기초 개념 잡기 (필독!)
챗봇이 사람의 말을 알아듣고 똑똑하게 행동하려면 두 가지가 필요합니다.
1. **Intent (의도):** 사용자가 "비밀번호 어떻게 바꿔?"라고 물어볼 때, 챗봇이 "아, 이 사람은 **[사용자 관리 화면으로 이동]**하고 싶구나!"라고 파악하는 기준입니다.
2. **Action (실행):** 챗봇이 의도를 파악한 후, 실제로 "사용자 관리 화면으로 **[화면 이동]**시켜주는 기능"입니다.

> 💡 **J-Brain의 철학 (Top-Down 방식):**
> J-Brain은 기획자가 편하게 작업할 수 있도록 **"의도(Intent)를 먼저 자유롭게 만들고, 나중에 실행(Action)을 끼워 맞추는"** 방식을 권장합니다. 따라서 본 가이드도 이 순서대로 진행됩니다!

---

## 🛠 실전 테스트: 시나리오 1. (화면 이동 메뉴 만들기)
사용자가 "비밀번호 변경하고 싶어"라고 말하면, 챗봇이 [사용자 관리 화면]을 띄워주는 기능을 만들어 보겠습니다.

### Step 1. 사용자의 의도(Intent) 먼저 만들기
1. 화면 맨 왼쪽(검은색 사이드바) 메뉴를 확인합니다.
2. 위쪽의 **[워크플로우 어시스턴트]** 그룹 아래에 있는 **`03. 의도 설계`** 메뉴를 클릭합니다.
3. 화면 중앙에 나타난 큼직한 버튼들 중, 첫 번째에 있는 **`[+ 신규 Intent ->]`** 버튼을 클릭합니다.
4. 우측에서 하얀색 서랍(Drawer) 화면이 열립니다. 아래와 같이 꼼꼼히 입력해 주세요.

| 입력 항목 | 어떻게 입력하나요? |
| :--- | :--- |
| **Intent ID** | 회색으로 잠겨 있습니다. (시스템이 자동 생성하므로 무시하세요) |
| **Intent 이름** | `사용자 관리 화면 이동` 이라고 적어주세요. |
| **Category** | 드롭다운을 눌러서 `navigate` (화면 이동)를 선택해 주세요. |
| **Action 연결** | 🚨 **주의:** 꼭 **`Action 선택 전`** 으로 그대로 두세요! (아직 안 만들었으니까요) |
| **Status** | `active` (활성화)를 선택해 주세요. |
| **우선순위** | `100` (기본값 그대로 둡니다) |

5. **[예시 질문]** 항목에는 사용자가 할 법한 질문들을 등록합니다. 아래 문장들을 복사해서 넣고 엔터(Enter)나 우측의 `[추가]` 버튼을 눌러 하나씩 등록해 주세요.
   - `비밀번호 변경하고 싶어`
   - `사용자 관리 메뉴가 어디야?`
   - `내 계정 정보 수정할래`
6. 맨 아래의 남색 **`[저장]`** 버튼을 누릅니다. (성공적으로 저장되었다는 알림을 확인하세요!)

#### Step 1-2. Action 후등록 및 연결 (4단계 실행 연결)
1. 왼쪽 사이드바 메뉴에서 **`04. 실행 연결`** 메뉴를 클릭합니다.
2. 화면 상단 초록색 배너 우측의 **`[Action 빠른 등록]`** 버튼을 클릭하여 아래 정보를 입력하고 저장합니다.
   - **Action 이름:** `사용자 관리 화면 이동`
   - **Action 유형:** `NAVIGATE`
   - **메뉴명:** `사용자 관리`
   - **화면 URL:** `/admin/users`
3. Action 저장 후, 화면에 보이는 '미연결 Intent' 목록에서 우리가 만든 `사용자 관리 화면 이동` 우측의 **`[열기]`** 버튼을 누릅니다.
4. Intent 상세 화면이 열리면 **`[Action 연결]`** 드롭다운에서 방금 만든 `사용자 관리 화면 이동` Action을 찾아 **선택**합니다.
5. 맨 아래 **`[저장]`** 버튼을 누릅니다. (짝짓기 완료!)

🎉 **축하합니다! 시나리오 1번 세팅이 완료되었습니다.**

---

## 🛠 실전 테스트: 시나리오 2. (지식 검색하게 만들기)
사용자가 "오류 났어요"라고 하면 챗봇이 FAQ 문서를 뒤져서 답변해주게 만들어 보겠습니다.

### Step 1. 챗봇이 검색할 지식(FAQ) 미리 적어두기
1. 화면 맨 왼쪽 사이드바에서 (조금 아래로 내려가서) **[의도/Action]** 그룹 안의 **`FAQ 관리`** 메뉴를 클릭합니다.
2. 화면 우측 상단의 **`[+ 신규 등록]`** 버튼을 누릅니다.
3. 아래와 같이 질문과 답변을 등록합니다.
   - **질문:** `시스템 오류가 발생했어요`
   - **답변:** `시스템 오류 발생 시 아래 순서대로 조치해 주세요. 1. 브라우저 캐시 삭제 2. 관리자 문의`
   - **상태:** `active`
4. **`[저장]`** 버튼을 누릅니다.

### Step 2. 사용자의 의도(Intent) 만들기
1. 왼쪽 사이드바 메뉴에서 다시 **`03. 의도 설계`** 메뉴로 돌아갑니다.
2. **`[+ 신규 Intent ->]`** 버튼을 클릭하여 아래 정보를 넣습니다.
   - **Intent 이름:** `시스템 오류 해결 안내`
   - **Category:** `SEARCH_DOC` (문서 검색)
   - **Action 연결:** 🚨 **`Action 선택 전`** 그대로 두기!
   - **예시 질문:** `시스템 오류가 발생했어요`, `에러가 나서 작업이 안 돼요` (추가 버튼 누르기)
3. **`[저장]`** 버튼을 누릅니다.

### Step 3. 행동(Action) 만들고 짝지어주기
1. 왼쪽 사이드바 메뉴에서 **`04. 실행 연결`** 메뉴로 이동합니다.
2. 초록색 배너 우측 상단의 **`[Action 빠른 등록]`** 버튼을 클릭하여 아래 정보를 저장합니다.
   - **Action 이름:** `시스템 오류 해결 가이드 검색`
   - **Action 유형:** `SEARCH_DOC`
   - **실행 방식:** `local`
3. 미연결 Intent 목록에서 `시스템 오류 해결 안내` 우측의 **`[열기]`** 버튼을 누릅니다.
4. Intent 상세 화면의 **`[Action 연결]`** 드롭다운에서 방금 만든 `시스템 오류 해결 가이드 검색`을 선택합니다.
5. 화면 맨 우측 상단(위쪽)에 있는 파란색 **`[저장]`** 버튼을 누릅니다. (주의: 화면 맨 아래의 '연결 저장' 버튼은 누르지 마세요!)

🎉 **시나리오 2번 세팅 완료!**

## 🚀 대망의 마지막 단계: 챗봇에 적용(빌드)하고 대화해보기!

> [!WARNING]
> 지금까지 우리가 한 작업은 DB에 정보를 저장한 것일 뿐, 아직 실제 챗봇의 뇌(모델)에는 주입되지 않았습니다. 반드시 아래의 **빌드 및 배포** 과정을 거쳐야 합니다!

### Step A. 챗봇 두뇌 굽기 (Pack 빌드)
1. 왼쪽 사이드바 메뉴에서 **`05. Pack 배포/빌드`** (또는 `Pack Builder`) 메뉴를 클릭합니다.
2. 화면에 보이는 **`[Pack 빌드]`** (또는 Export) 버튼을 누릅니다.
3. 챗봇이 아까 우리가 넣은 정보들을 열심히 공부(빌드)합니다. "성공적으로 빌드되었습니다" 라는 메시지가 뜰 때까지 잠시 기다려 주세요.

### Step B. 완성된 두뇌 적용하기 (배포)
1. 왼쪽 사이드바 메뉴에서 **`Pack Repository`** (또는 `버전배포 관리`) 메뉴를 클릭합니다.
2. 방금 생성된 따끈따끈한 버전의 항목을 찾아서 **`[적용]`** (또는 Activate) 버튼을 클릭합니다.

### Step C. 런타임 환경에서 대화해보기 💬
1. 화면 왼쪽 사이드바 메뉴에서 **`런타임`** 그룹 안의 **`Action 실행 테스트`** 메뉴를 클릭합니다.
2. 화면 중앙의 검색창(Query Input)에 직접 질문을 쳐서 **[Run]** (또는 테스트 실행) 버튼을 눌러봅니다.

| 당신이 칠 질문 | 기대되는 훌륭한 라우팅 결과 |
| :--- | :--- |
| `비밀번호 변경하고 싶어` | **Action 유형:** `NAVIGATE_MENU` / "사용자 관리" 화면으로 라우팅됨 |
| `시스템 오류가 발생했어요` | **Action 유형:** `SEARCH_DOC` / FAQ에서 아까 적어둔 조치 방법 반환됨 |

> [!TIP]
> **보너스 테스트:** 아까 예시 질문으로 적었던 문장과 "살짝 다르게" 물어보세요. (예: `비번 어떻게 바꿔?`) AI가 찰떡같이 알아듣고 사용자 관리 메뉴 Action을 뱉어낸다면 완벽하게 성공한 것입니다!
