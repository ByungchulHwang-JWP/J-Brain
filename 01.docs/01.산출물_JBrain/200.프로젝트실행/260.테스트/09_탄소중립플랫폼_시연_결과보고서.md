# 📊 [보고서] J-Brain 기반 탄소 중립 플랫폼 MVP 구축 완료 및 시연 보고서

**작성일자:** 2026. 07. 05  
**작성자:** JWP 개발팀  
**문서 목적:** 본 문서는 기 승인된 『고객 내부망 환경 챗봇 제공 방안』 장표의 목표(7월 중순 MVP 시연)를 성공적으로 달성함에 따라, **현재 구현 완료된 J-Brain 플랫폼의 실제 작동 구조와 탄소 중립 플랫폼 파일럿 적용 결과**를 경영진(또는 고객사)에 보고하기 위한 High-End급 프레젠테이션/보고서 초안입니다.

---

## 📑 Executive Summary (요약)
당초 계획한 **"생성형 LLM의 보안/비용/환각 문제를 해결하는 경량 NLU + Action 기반 공통 챗봇 플랫폼(J-Brain)"**의 1차 MVP(C-lite) 개발이 완료되었습니다. 
특히 **탄소 중립 플랫폼을 1차 파일럿 서비스로 선정**하여, 의도(Intent) 설계부터 Pack 빌드, 런타임 배포 및 실제 챗봇 시연까지 이어지는 **Intent Factory 운영 파이프라인 전체를 성공적으로 검증**하였습니다.

---

## 📝 슬라이드별 보고 스크립트 및 구성안 (업데이트 버전)

기존 계획안 장표(1~15)의 목차를 유지하되, **'제안/계획'** 단계였던 내용을 **'구현 완료 및 검증 결과'** 로 최신화하여 작성했습니다. 시연(Live Demo)과 함께 띄워놓고 발표하기 최적화된 형태입니다.

### [Slide 1~3] 추진 배경 및 문제 해결 방식 (리마인드)
- **배경 (As-Is):** 폐쇄망 환경의 보안 규제, On-Premise LLM 구축의 막대한 비용, 생성형 AI 특유의 할루시네이션(환각) 문제로 인해 기업 내부망 챗봇 도입이 지연됨.
- **해결책 (To-Be):** LLM에 전적으로 의존하지 않고, **J-Brain 공통 챗봇 엔진(경량 NLU)과 서비스별 두뇌 팩(Intent Pack)을 완벽히 분리**하는 아키텍처를 고안함.
- **검증 완료:** 이번 MVP 구축을 통해 외부망(Intent Factory)에서 팩을 만들어 내부망(Runtime)으로 Import 하는 구조가 실제 보안 제약을 준수하면서도 높은 성능을 냄을 입증함.

### [Slide 5~6] 구현된 아키텍처 및 공통화 전략
- **분리형 아키텍처 실증:** 
  - **공통 플랫폼 (JWP 제공):** NLU 라우팅, 매칭 엔진, 검색 런타임 등 변하지 않는 '엔진' 역할 완벽 수행.
  - **서비스별 Intent Pack:** 탄소 중립 플랫폼에 특화된 지식만을 JSON 형태로 압축하여 무거운 재구축 없이 원클릭으로 챗봇 지능을 교체/확장하는 모습 구현 완료.
- **👉 (시연 포인트 연계):** 시연 가이드의 `[1. 신규 프로젝트 등록]` 단계가 바로 이 멀티테넌시 공통화 플랫폼의 강력함을 보여주는 부분입니다.

---

### [Slide 7] 🌟 탄소중립플랫폼 파일럿 적용 결과 (시연 핵심)
1차 파일럿으로 선정된 탄소중립플랫폼의 주요 업무를 Intent Pack으로 구성하여 성공적으로 챗봇에 이식했습니다.

1. **상태 진단 / 시세 조회:** "오늘 KAU 탄소 배출권 시세 알려줘" ➔ 실시간 API 연동 답변.
2. **사내 규정 / 매뉴얼 검색:** "사용자 인증 절차 알려줘" ➔ 등록된 매뉴얼 PDF 기반 할루시네이션 없는 정답 및 출처(Source) 제시.
3. **업무 화면 바로가기:** "탄소 배출 현황 띄워줘" ➔ 해당 대시보드 URL로 즉시 이동하는 Action 버튼 제공.

---

### [Slide 10~13] Intent Factory 파이프라인 작동 검증
단순히 챗봇 화면만 만든 것이 아니라, 챗봇을 유지보수하고 똑똑하게 키워나가는 **'공장(Factory) 파이프라인' 전체를 UI로 구현**했습니다.

- **[Slide 11] Pack 구성 요소 완비:** Intent, Entity/Synonym(유의어 사전), Action, FAQ 등 장표에서 기획했던 모든 JSON 구성 요소가 J-Brain 관리자 웹 화면에서 제어 가능합니다.
- **[Slide 12] Pack 생성 자동화:** 지식 업로드 ➔ AI 의도 자동 추출 ➔ 수동 Action 연결 ➔ 무결성 검증 ➔ 버전업 빌드(`v0.1.0`)에 이르는 원스톱 툴이 완성되었습니다.
- **👉 (시연 포인트 연계):** 시연 가이드의 `[3. 의도 설계] ~ [5. Pack 검증 및 빌드]` 단계에서 이 강력한 관리자 경험(Admin UX)을 직접 눈으로 확인하실 수 있습니다.

---

### [Slide 14] 보안 및 운영 원칙 적용
- **데이터 유출 차단:** 내부 지식 문서와 FAQ는 철저히 폐쇄망(Runtime) 내에서만 검색되며, 외부 LLM API 호출을 최소화하는 하이브리드 RAG 정책을 적용했습니다.
- **White-box 모니터링:** 챗봇이 왜 그런 대답을 했는지, 점수(Score)와 매칭된 Intent를 관리자가 명확하게 들여다볼 수 있는 `Runtime QA 대화 테스트` 도구를 탑재하여 운영 안정성을 확보했습니다.

---

### [Slide 15] 향후 계획 (Next Steps)
본 MVP 시연을 기점으로 다음과 같은 확산 계획을 제안합니다.

1. **시연 완료 후:** 탄소중립플랫폼 파일럿에 대한 보완점 수렴 및 UI/UX 디테일 폴리싱.
2. **수평 전개 (Horizontal Roll-out):** 탄소 중립 외에 HR, 재무, IT Helpdesk 등 사내 타 시스템으로 신규 프로젝트(Tenant)를 생성하여 챗봇 적용 범위 확대.
3. **고도화 과제:** 1차 제외 범위였던 동적 DB 조회(Text-to-SQL) 및 복합 Action(등록/수정) 기능에 대한 R&D 착수.
