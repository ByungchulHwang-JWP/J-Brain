## 2. 작성 기준

본 질문셋은 실제 운영 데이터 확정 전 단계에서 내부 가정 기반으로 작성한 PoC 검증용 데이터이다. 질문은 사용자가 챗봇에 입력할 가능성이 높은 자연어 표현을 기준으로 구성하며, Intent Matcher, Entity Extractor, Confidence Router, Action Router 검증에 사용한다.

질문 유형은 다음과 같이 분류한다.

| 질문 유형 | 설명 |
|---|---|
| 문서/FAQ | 산정 기준, Scope 기준, 배출계수, 용어 등 지식 검색형 질문 |
| 화면 이동 | 배출량 입력, 보고서 등 메뉴 위치 또는 화면 이동 질문 |
| 사용 방법 | 업무 절차, 입력 방법, 등록 방법 안내 질문 |
| 조회형 Action | 배출량, 전력 사용량, 미입력 현황 등 데이터 조회 질문 |
| 오류 안내 | 권한 오류, 메뉴 접근 불가, 다운로드 실패 등 조치 안내 질문 |
| Fallback | Intent 매칭이 낮거나 보완이 필요한 미분류 질문 |

## 6. PoC 우선순위

### 6.1 P0 검증 질문
P0는 1차 PoC에서 반드시 통과해야 하는 핵심 질문이다.

| 질문 번호 | 기대 Intent | 사유 |
|---|---|---|
| 1~10 | INT-NZ-DOC-001~003 | 문서/FAQ 검색형 핵심 |
| 14~19 | INT-NZ-NAV-001~002 | 화면 이동 핵심 |
| 21~23 | INT-NZ-GUIDE-001 | 사용 방법 안내 핵심 |
| 27~38 | INT-NZ-QUERY-001~003 | Mock Query Action 핵심 |
| 42~45 | INT-NZ-ERR-001 | 오류 안내 핵심 |

### 6.2 P1 검증 질문
P1은 1차 PoC에서 가능하면 검증하되, Candidate 또는 Fallback 품질 확인에 활용한다.

| 질문 번호 | 기대 Intent | 사유 |
|---|---|---|
| 11~13 | INT-NZ-DOC-004 | 용어 설명 Candidate |

| 46~50 | INT-NZ-ERR-001, INT-NZ-FBK-001 | 오류/미응답 처리 확인 |

## 8. 보완 필요사항

| 항목 | 보완 내용 |
|---|---|
| 공장/현장 마스터 | A공장, B공장, B현장은 PoC용 가상값이며 실제 코드 매핑 필요 |
| 메뉴명 | 배출량 입력, 전력 사용량 입력, 보고서는 실제 메뉴 ID 확인 필요 |
| 기간 정규화 | 작년, 올해, 이번 달, 1분기 등 상대 기간 표준화 필요 |
| Candidate Intent | 추이 조회, Scope별 비교, 감축 실적은 1차 이후 실제 데이터 구조 확인 필요 |
| Fallback 기준 | 예측, 세금 계산, 정책 해석 등 1차 범위 외 질문 분류 기준 보강 필요 |
