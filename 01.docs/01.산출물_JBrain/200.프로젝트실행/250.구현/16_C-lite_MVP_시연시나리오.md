# 16. C-lite MVP 시연 시나리오

## 1. 문서 개요

| 항목 | 내용 |
|---|---|
| 문서명 | C-lite MVP 시연 시나리오 |
| 작성일 | 2026-06-25 |
| 버전 | v0.1 |
| 목적 | 2026년 7월 중순 대표님 보고/시연을 위한 공통 챗봇 프레임워크 MVP 시연 흐름 정의 |
| 기준 방향 | C 방안 중 7월 중순 시연 가능한 C-lite 범위 |

## 2. 시연 목표

시연의 목적은 완성형 챗봇 제품을 보여주는 것이 아니라, 다음 3가지를 증명하는 것이다.

1. 외부 LLM 없이도 사용자 자연어를 업무 Intent로 분류할 수 있다.
2. 서비스별 Intent Pack을 통해 화면 이동, 문서 검색, 제한 조회 Action을 실행할 수 있다.
3. 탄소중립플랫폼 파일럿을 기준으로 동일 구조를 다른 자사 프로젝트에도 확장할 수 있다.

## 3. 시연 범위

| 범위 | 포함 여부 | 설명 |
|---|:---:|---|
| 자연어 → 화면/기능 이동 | O | 메뉴/화면 라우팅 Action 반환 |
| 자연어 → 문서/FAQ/자료실 검색 | O | 로컬 인덱스 기반 근거 문단 반환 |
| 자연어 → 정형 조회 | 제한 포함 | Mock 또는 시스템 통계 API 2~3개 |
| 자유 SQL 생성 | X | 보안상 제외 |
| 외부 LLM 호출 | X | 내부망 대응 원칙상 제외 |
| 등록/수정/삭제 | X | 변경성 Action 제외 |
| 다운로드 | X 또는 보류 | 2차 확장 후보 |

## 4. 데모 데이터 준비

### 4.1 Intent Pack

탄소중립플랫폼 Pack v0.1을 기준으로 한다.

필수 구성:

```text
netzero-intent-pack/
 ├─ service_profile.json
 ├─ intents.json
 ├─ intent_examples.json
 ├─ entities.json
 ├─ entity_synonyms.json
 ├─ action_registry.json
 ├─ screen_routes.json
 ├─ faqs.json
 ├─ approved_documents.json
 └─ validation_questions.json
```

### 4.2 문서/FAQ 인덱싱 대상

| 대상 | 용도 |
|---|---|
| 탄소중립플랫폼 소개 페이지 주요 메뉴/설명 | 플랫폼/서비스 소개 검색 |
| FAQ/자료실 샘플 문서 | 문서 검색 Action |
| J-Brain Manual 또는 관리자 매뉴얼 | 공통 프레임워크 문서 검색 예시 |
| 탄소 배출량/Scope/배출계수 안내 문서 | 탄소중립 파일럿 질의응답 |

### 4.3 Mock 조회 데이터

| Action | Mock 응답 예시 |
|---|---|
| 등록 프로젝트 수 조회 | 등록된 프로젝트 1개 |
| Source 문서 수 조회 | 총 Source 1건 |
| 최근 인덱싱 성공 이력 | J-Brain Manual.txt, SUCCESS |
| 탄소 배출량 조회 | A공장 2024년 배출량 Mock 카드 |
| 전력 사용량 조회 | B현장 당월 전력 사용량 Mock 카드 |

## 5. 시연 화면 흐름

### Scene 1. 관리자 대시보드

목적: 이미 공통 챗봇 관리 시스템의 운영 화면이 준비되어 있음을 보여준다.

확인 포인트:

- 등록 도메인/프로젝트 수
- Source 문서 수
- 인덱싱 작업 이력
- PostgreSQL 연결 상태
- AI 챗봇 대화 테스트 메뉴
- 시스템 프롬프트/로그/권한 메뉴

### Scene 2. 문서 등록 및 인덱싱

질문 전에 문서/FAQ가 로컬 인덱싱되어 있음을 보여준다.

시연 문구:

```text
고객 내부망에서는 고객 문서를 외부로 보내지 않고,
내부망 서버에서 로컬 인덱싱합니다.
```

### Scene 3. 화면/기능 이동 Action

사용자 질문:

```text
인덱싱 작업 현황 보여줘
```

기대 결과:

```json
{
  "type": "navigate",
  "intent": "인덱싱 작업 현황 화면 이동",
  "confidence": "HIGH",
  "route": "/admin/index-jobs",
  "button_label": "인덱싱 작업 현황 열기"
}
```

대표 메시지:

```text
챗봇이 답변을 지어내는 것이 아니라,
승인된 화면 이동 Action을 찾아 사용자에게 실행 버튼을 제공합니다.
```

### Scene 4. 문서/FAQ 검색 Action

사용자 질문:

```text
온실가스 인벤토리 관리는 어떤 서비스야?
```

기대 결과:

```json
{
  "type": "search_doc",
  "intent": "서비스 소개 문서 검색",
  "confidence": "HIGH",
  "answer": "온실가스 인벤토리관리 관련 근거 문단 요약",
  "sources": [
    {
      "title": "탄소중립플랫폼 소개",
      "section": "온실가스 인벤토리관리"
    }
  ]
}
```

대표 메시지:

```text
LLM 생성 답변이 아니라, 내부망에 인덱싱된 승인 문서에서 근거 문단을 찾아 답합니다.
```

### Scene 5. 제한된 정형 조회 Action

사용자 질문:

```text
최근 인덱싱 성공 이력 알려줘
```

기대 결과:

```json
{
  "type": "query",
  "intent": "최근 인덱싱 이력 조회",
  "confidence": "HIGH",
  "confirmation_required": false,
  "data": {
    "source": "J-Brain_Manual.txt",
    "status": "SUCCESS",
    "elapsed": "17시간 전"
  }
}
```

대표 메시지:

```text
정형 데이터 조회는 자연어 SQL 생성이 아니라,
사전에 승인된 API 또는 SQL Template만 실행합니다.
```

### Scene 6. Confidence/Fallback

사용자 질문:

```text
대표님이 원하는 그거 해줘
```

기대 결과:

```json
{
  "type": "fallback",
  "confidence": "VERY_LOW",
  "message": "질문 의도를 확인하지 못했습니다.",
  "logged": true
}
```

대표 메시지:

```text
확신이 낮은 질문은 억지로 실행하지 않고 미응답 질문으로 기록하여 Intent Pack을 개선합니다.
```

## 6. 시연 질문 세트

| 번호 | 질문 | 기대 Action |
|---:|---|---|

| N2 | 문서 목록 열어줘 | `/admin/sources` 이동 |
| N3 | AI 챗봇 테스트 화면으로 가줘 | `/admin/chat-test` 이동 |
| N4 | 시스템 프롬프트 관리 보여줘 | `/admin/prompts` 이동 |
| N5 | 사용 로그 조회 화면 열어줘 | `/admin/logs` 이동 |

| 번호 | 질문 | 기대 결과 |
|---:|---|---|
| D1 | 탄소중립플랫폼이 뭐야? | 플랫폼 소개 문서 검색 |

| D3 | 재생에너지 직접공급관리는 어디서 확인해? | 문서 검색 또는 화면 이동 후보 |

## 7. 수용 기준

| 항목 | 기준 |
|---|---:|
| 화면 이동 질문 Top-1 정확도 | 90% 이상 |
| 문서/FAQ 검색 질문 Top-1 정확도 | 80% 이상 |
| 제한 조회 Action Routing 성공률 | 95% 이상 |
| 잘못된 Action 실행률 | 1% 이하 |
| Fallback 기록 성공률 | 100% |
| 외부 LLM/API 호출 | 0건 |
| 고객 데이터 외부 전송 | 0건 |

## 8. 시연 성공 조건

시연은 다음 메시지가 전달되면 성공으로 본다.

```text
이 구조는 탄소중립플랫폼 전용 챗봇이 아니라,
서비스별 Intent Pack을 교체하여 자사 여러 프로젝트에 붙일 수 있는
폐쇄망 대응형 공통 챗봇 프레임워크입니다.
```
