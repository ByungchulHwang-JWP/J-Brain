# 02. 7월 중순 개발 스프린트 계획

## 1. 문서 개요

| 항목 | 내용 |
|---|---|
| 문서명 | 7월 중순 개발 스프린트 계획 |
| 작성일 | 2026-06-25 |
| 버전 | v0.1 |
| 목표일 | 2026년 7월 중순 |
| 목적 | C-lite MVP 시연을 위한 개발, 검증, 보고 준비 작업을 주차별로 정리 |

## 2. 목표

2026년 7월 중순까지 대표님께 다음 내용을 시연한다.

```text
자사 모든 프로젝트에 적용 가능한 폐쇄망 대응형 공통 챗봇 프레임워크의
C-lite MVP를 탄소중립플랫폼 파일럿 기준으로 동작 검증한다.
```

## 3. 스프린트 원칙

| 원칙 | 설명 |
|---|---|
| 시연 우선 | 운영 전체 기능보다 대표님이 이해할 수 있는 end-to-end 흐름을 우선한다. |
| 공통 구조 우선 | 탄소중립 전용 코드보다 Intent Pack 기반 공통 구조를 우선한다. |
| 외부 LLM 금지 | MVP 시연에서는 외부 LLM/API 호출을 사용하지 않는다. |
| Action 제한 | 화면 이동, 문서 검색, 제한 조회만 포함한다. |
| Mock 허용 | 실제 DB/API 미확정 영역은 Mock Action으로 시연한다. |
| 로그 남김 | 미응답 질문, Intent 매칭 결과, Action 실행 결과는 운영 개선 근거로 남긴다. |

## 4. 남은 핵심 개발 범위

| 구분 | 개발 항목 | 상태 기준 |
|---|---|---|
| Pack Runtime | Intent Pack Loader | `NETZERO` Pack 로드 가능 |
| NLU | Intent Matcher | Top-1/Top-3 후보 반환 |
| NLU | Entity Extractor | 메뉴, 주제, 기간, 공장/현장 추출 |
| NLU | Confidence Router | High/Medium/Low/Very Low 분기 |
| Action | Action Router | Intent → Action ID 매핑 |
| Action | Navigation Action | Route/button 응답 반환 |
| Action | Search Doc Action | 로컬 문서 검색 결과 반환 |
| Action | Query Mock Action | 3개 이상 카드 응답 |
| 운영 | Unanswered Logging | 미응답 질문 저장 |
| Frontend | Chat Test UI | 응답 카드/버튼/근거 표시 |
| QA | Validation Runner | 질문셋 자동 검증 |
