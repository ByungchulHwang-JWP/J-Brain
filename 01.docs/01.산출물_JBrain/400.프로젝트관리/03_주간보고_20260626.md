| 구분 | 진행 내용 | 산출/결과 |
|---|---|---|
| Intent Matcher | 외부 LLM/API 없이 로컬 CPU 기반 Intent Matcher 구현 | 사용자 질문 입력 시 Top-1/Top-3 Intent 후보 반환 |
| Entity Extractor | 공장/현장, 메뉴, Scope, 기간, 주제 등 Entity 추출 구현 | Validation 기준 Entity 추출 정확도 확보 |
| Confidence Router | High/Medium/Low/Very Low 신뢰도 분기 구현 | Low/Very Low 질문은 Action 실행 차단 후 Fallback 처리 |
| Action Router | Intent 결과를 Action 카드로 변환하는 1차 Router 구현 | Navigation, Search Doc, Query Mock, Fallback 카드 반환 |
| 제한 조회 | 실제 SQL/API 대신 Mock Query Action 구현 | 배출량, 전력 사용량, 미입력 현황 등 시연용 응답 구성 |
| 미응답 로그 | 의도 불명 또는 범위 밖 질문 기록 구조 구현 | Fallback 질문을 후속 Pack 개선 대상으로 관리 가능 |

## 3. 금주 주요 성과

1. 기존 GraphRAG/LLM 중심 방향에서 폐쇄망 대응형 Lightweight NLU + Action 구조로 1차 전환 방향을 정리했다.
2. 제안 아키텍처와 동일하게 외부망의 Intent Pack 생성/검증 영역과 고객 내부망의 Pack Runtime 영역을 분리하는 구조를 문서와 구현에 반영했다.
3. 탄소중립플랫폼을 기준 서비스로 삼아 Intent Pack, Pack Loader, Intent Matcher, Action Router, Validation Runner까지 C-lite MVP 핵심 흐름을 구성했다.
4. 외부 LLM/API 호출 없이 화면 이동, 문서 검색, 제한 조회, Fallback 로그가 가능한 시연 가능한 end-to-end 구조를 확보했다.
5. 7월 중순 대표님 시연을 위한 기능 범위와 잔여 작업을 구체화했다.
