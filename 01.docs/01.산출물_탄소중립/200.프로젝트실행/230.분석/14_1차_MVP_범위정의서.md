## 2. 1차 MVP 구현 범위 (In-Scope)
본 MVP의 최우선 목적은 **[탄소중립플랫폼]** 내에 정상 작동하는 GraphRAG 기반 챗봇을 안착시키면서, 아키텍처는 **[멀티 테넌트]** 구조를 미리 깔아두는 것입니다.

1. **기반 아키텍처 (Platform Core)**
   - Workspace(테넌트) 생성 및 데이터 격리 DB 구조 적용.
   - `NETZERO`(탄소중립)라는 단일 Workspace 초기 세팅.
   - 사내 SSO 연동 및 System Admin / Workspace Admin 분리.
2. **사용자 서비스 (FO)**
   - 탄소중립플랫폼 사용자 페이지 내 우측 하단 챗봇 위젯 삽입.
   - 타이핑 효과, 추천 질문 기능, 출처 링크 기능, 피드백 전송 기능.
3. **관리자 서비스 (BO)**
   - 탄소중립플랫폼 관리를 위한 대시보드.
   - 챗봇 인사말/시스템 프롬프트 설정.
   - 도메인 문서(PDF) 수동 업로드, 단답형 FAQ 수동 등록 기능.
   - 사용자 대화 로그 조회 및 피드백 조회.
4. **AI 파이프라인 (GraphRAG)**
   - 탄소중립 도메인 문서에 대한 텍스트 파싱 및 Vector Embedding 구현.
   - 기본 수준의 엔티티 추출 및 관계 맵핑(Graph Store) 연동.

## 3. 2차 확장 및 고도화 범위 (Out-of-Scope for MVP)
아래 기능들은 1차 MVP에는 포함되지 않으며, 차기 DPPA 또는 K-Ads 등으로 프로젝트가 본격 확장될 때 순차 도입합니다.

1. **지식 연동 자동화 (Auto-Sync)**
   - [2차] 사내 Confluence, Jira, 그룹웨어 등 외부 저장소와 주기적으로 API를 연동하여 지식을 자동 인덱싱하는 기능.
2. **멀티 모달 (Multi-Modal) 답변**
   - [2차] 답변 내에 관련 이미지, 표, 차트 등을 직접 렌더링하여 보여주는 기능 (현재는 텍스트+출처 링크까지만 제공).
3. **고도화된 통계 분석 대시보드**
   - [2차] 사용자 질의 패턴을 클러스터링하여 신규 지식 트렌드를 자동 도출해주는 기능.
4. **사용자 개인화 (Personalization)**
   - [2차] 사용자의 소속 부서나 과거 질의 내역을 바탕으로 프롬프트를 자동으로 튜닝하여 맞춤형 답변을 제공하는 기능.

## 4. 리스크 및 주요 확인 사항
- **오픈소스 제약**: 현재 검토된 `pgvector` 기반 검색 성능이 문서 10만 건 이상일 때 응답 시간 3초를 보장할 수 있는지 MVP 기간 내 부하 테스트(Load Test) 필수.
- **LLM 비용 문제**: GPT-4o 등 상용 LLM 사용 시 프로젝트별 과금 주체가 명확해야 하며(사내 공통 예산 vs 팀별 예산), 이를 통제하기 위해 일일 토큰 한도(Rate Limit) 설정이 시급함.
