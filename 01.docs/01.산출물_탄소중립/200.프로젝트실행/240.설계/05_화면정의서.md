## 2. 사용자 사이트 (Front-Office)
각 프로젝트(탄소중립, DPPA 등)의 메인 서비스 우측 하단에 공통 위젯 형태로 삽입됩니다.

| 화면 ID | 화면명 | 주요 기능 | 입력 항목 | 출력 항목 | 버튼/액션 | 권한 | 비고 |
|---|---|---|---|---|---|---|---|
| FO-001 | 챗봇 플로팅 버튼 | 챗봇 호출 및 닫기 | - | 위젯 아이콘(기본/로고 적용 가능) | 열기/닫기 | End User | Workspace ID에 따른 디자인(로고/색상) 동적 로드 |
| FO-002 | 챗봇 대화창 | 질의 응답 메인 창 | 사용자 질문 입력창 | 대화 내역(말풍선), Typing 애니메이션 | 새 대화 시작, 질문 전송, 챗봇 창 닫기 | End User | Markdown 렌더링 지원 |
| FO-003 | 추천 질문 영역 | 빠른 질문 유도 | - | 챗봇 설정에 등록된 추천 질문 목록 | 추천 질문 칩 클릭 | End User | 대화창 상단 또는 빈 대화창 표출 |
| FO-004 | 답변/출처 표시 영역 | 신뢰도 향상 및 근거 제시 | - | LLM 답변 문구, 인용 출처(문서명, 유사도 점수) | 출처 칩 클릭 시 원문 위치 또는 파일명 모달 표시 | End User | - |
| FO-005 | 피드백 영역 | 답변 품질 평가 | 텍스트(선택적 개선 의견) | 좋아요(👍)/싫어요(👎) 아이콘 | 피드백 제출 버튼 | End User | 관리자 피드백 수집용 |
| FO-006 | 장애/오류 안내 | 시스템 오류 및 민감정보 필터링 알림 | - | "해당 지식을 찾을 수 없습니다" 등 기본 Fallback 문구 | 재시도 버튼 | End User | 챗봇 설정에서 문구 변경 가능 |

## 3. 관리자 사이트 (Back-Office)

### 3.1 플랫폼 통합 관리 (System Admin 전용)
| 화면 ID | 화면명 | 주요 기능 | 입력 항목 | 출력 항목 | 버튼/액션 | 권한 | 비고 |
|---|---|---|---|---|---|---|---|
| BO-001 | 전체 대시보드 | 플랫폼 전체 현황 조회 | 날짜 필터 | 전체 Workspace별 챗봇 사용량, 토큰 누적 수, 활성 사용자 수 등 | 기간 검색 | System Admin | - |
| BO-002 | Workspace 목록 | 프로젝트(Tenant) 관리 | 검색어, 상태 | Workspace ID, 프로젝트명, 관리자명, 생성일 | 신규 추가, 상세 조회 | System Admin | - |
| BO-003 | Workspace 상세 | 개별 프로젝트 환경 설정 관리 | Workspace명, 설명, 상태 | 현재 설정 정보 | 저장, 비활성화 | System Admin | - |

### 3.2 개별 프로젝트 관리 (Workspace 단위 종속)
*아래 화면들은 접속한 계정의 Workspace 권한에 종속되어 동작합니다.*

| 화면 ID | 화면명 | 주요 기능 | 입력 항목 | 출력 항목 | 버튼/액션 | 권한 | 비고 |
|---|---|---|---|---|---|---|---|
| BO-004 | 챗봇 설정 | 챗봇 UI/UX 기본 세팅 | 이름, 웰컴 메시지, Primary Color | 현재 설정된 UI 미리보기 | 적용/저장 | Workspace Admin | FO 디자인 연동 |
| BO-005 | 추천 질문 관리 | 초기 노출 질문 세팅 | 노출 순서, 질문 내용 | 등록된 추천 질문 리스트 | 추가, 삭제, 순서 변경 | Workspace Admin | 최대 5개 노출 |
| BO-006 | 시스템 프롬프트 | LLM 지시어(System Prompt) 관리 | 프롬프트 원문 텍스트 | 버전별 프롬프트 이력 탭 (v1, v2...) | 저장(신규 버전 생성), 이전 복원 | Workspace Admin | - |
| BO-007 | FAQ 관리 | 단답형 지식 수동 등록 | 질문(Q), 답변(A) | FAQ 리스트 | 엑셀 일괄 업로드, 수동 등록, 삭제 | Knowledge Manager | 최우선 검색 대상 |
| BO-008 | 문서(Source) 관리 | 지식 기반이 될 PDF/TXT 업로드 | 파일 선택, 카테고리 | 업로드된 파일명, 크기, 인덱싱 상태 | 업로드, 삭제 | Knowledge Manager | - |
| BO-009 | 인덱싱 관리 | 파이프라인 수동 트리거 | - | 작업 ID, 문서명, 청크 처리 진행률(Progress Bar) | 인덱싱 실행, 실패 건 재시도 | Knowledge Manager | - |
| BO-010 | Chunk / Entity Preview | 파싱 데이터 검수 | 검색 키워드 | 추출된 청크 텍스트, 엔티티 리스트, 관계(Relation) 테이블 | 상세 조회 | Knowledge Manager | GraphRAG 품질 확인용 |
| BO-011 | 챗봇 테스트 (Sandbox) | 배포 전 답변 테스트 (디버그 모드) | 질문 입력, 디버그 Toggle | 챗봇 답변, LLM 처리 소요 시간, 참조된 Chunk/Score 패널 | 질문 전송 | Knowledge Manager | 디버그 패널 필수 |
| BO-012 | 대화 로그 | 사용자 질의 이력 열람 | 기간, 사용자 ID | 날짜별 질의 내역, 토큰 수 | 엑셀 다운로드 | Operator | PII 데이터는 마스킹 처리 |
| BO-013 | 미응답 질문 관리 | 답변 실패(Fallback) 내역 집중 분석 | 기간 | 미응답 처리된 사용자 질문 목록 | 확인 상태 변경, 엑셀 다운 | Operator | FAQ 신규 작성의 근거 |
| BO-014 | 사용자 피드백 관리 | 좋아요/싫어요 평가 내역 조회 | 평가 종류(👍/👎) | 관련 질문, 챗봇 답변, 사용자 추가 코멘트 | 상태 변경 (조치 완료 등) | Operator | - |
| BO-015 | 권한 및 계정 관리 | 프로젝트 내 구성원 역할 할당 | SSO 사용자 이메일 검색 | 가입자 목록, 현재 부여된 Role (Admin/Manager/Operator 등) | 역할(Role) 선택 및 저장 | Workspace Admin | System Admin도 열람 가능 |
| BO-016 | 감사 로그 (Audit) | 관리자 활동 추적 (보안) | 날짜, 액션 종류 | 일시, 접속자 이메일, 수행한 Action(예: 프롬프트 수정) | - | Workspace Admin | 데이터 삭제 불가 |
