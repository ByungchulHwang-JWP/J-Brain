## 2. 권한별 기능 비교 요약 (비로그인 vs 로그인)

| 구분 | 비로그인 (Guest) | 로그인 (Member) |
| --- | --- | --- |
| **대화 이력 보존** | 현재 브라우저 세션(단기) 유지 | 계정 연동 영구 보존 및 멀티 디바이스 동기화 |
| **질문 권한/제한** | 일일 N회 제한 (예: 5회) | 무제한 (또는 높은 한도) |
| **지식 접근 범위** | 공개된 일반 탄소중립/규제 지식 | 사내 규정, 임직원 전용 비공개 지식 포함 |
| **개인화 기능** | 미지원 | 과거 질문 기반 컨텍스트 유지 및 북마크 기능 지원 |

## 3. 상세 기능 목록 (Feature List)

### 3.1 챗봇 기본 기능 (Core)

| --- | --- | --- | --- | :---: | --- |
| `FO-001` | 채팅 | 자연어 질의응답 | 사용자가 텍스트로 탄소 관련 질문을 입력하고 답변을 받음 | X | |
| `FO-002` | 채팅 | 스트리밍 답변 | LLM 응답 대기 시간을 줄이기 위해 타이핑 효과로 텍스트 출력 | X | |
| `FO-003` | 채팅 | 출처(Evidence) 표시 | 답변의 근거가 된 지식 문서명 및 매칭률을 하단 칩(Chip)으로 노출 | X | |
| `FO-004` | 채팅 | 출처 상세 보기 | 출처 칩 클릭 시, 원본 문서의 요약본(Chunk)을 모달창으로 확인 | X | |
| `FO-005` | 채팅 | 도메인 외 질문 차단 | 탄소/ESG와 무관한 질문 시 정중하게 답변 거절 (할루시네이션 방지) | X | |
