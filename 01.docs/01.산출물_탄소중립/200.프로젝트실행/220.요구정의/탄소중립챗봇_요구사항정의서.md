## 4. 기능 요구사항

### 4.1 챗봇 핵심 기능

| 요구사항 ID | 요구사항명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| FR-001 | GraphRAG 기반 질의응답 | 사용자 질문을 HybridRetriever(Vector+Graph 검색)로 관련 지식을 검색하고 LLM이 최종 답변을 생성한다. | 필수 |
| FR-002 | 출처(Evidence) 기반 답변 | 모든 답변에는 근거가 된 문서명과 청크 내용(출처)이 함께 제공되어야 한다. | 필수 |
| FR-003 | 스트리밍 응답 | 긴 답변의 경우 LLM 생성 결과를 실시간 스트리밍(SSE)으로 위젯에 표시한다. | 권장 |
| FR-004 | 대화 이력 유지 | 동일 세션 내에서 이전 대화 내용을 컨텍스트로 활용하여 연속 질의를 지원한다. | 필수 |
| FR-005 | 도메인 외 질문 거절 | 탄소 중립과 무관한 질문에 대해 답변을 정중히 거절하는 메시지를 반환한다. | 필수 |
| FR-006 | 다국어 지원 | 한국어 질문을 기본 지원하며, 영문 질문에 대해서는 한국어로 답변한다. | 권장 |

### 4.2 지식 관리 기능 (관리자)

| 요구사항 ID | 요구사항명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| FR-010 | 문서 업로드 및 Source 등록 | PDF, TXT, DOCX 형식의 문서를 업로드하고 도메인, 태그, 메타데이터를 함께 등록한다. | 필수 |
| FR-011 | 인덱싱 작업 실행 및 상태 추적 | 등록된 Source에 대한 파이프라인(파싱→청킹→임베딩→그래프 추출)을 실행하고, 진행률 및 완료 여부를 추적한다. | 필수 |
| FR-012 | 청크/엔티티/관계 Preview | 인덱싱 완료된 Source의 내부 데이터를 미리보기 형태로 확인한다. | 필수 |
| FR-013 | 답변 테스트 환경 | 관리자 화면에서 질의를 입력하고 GraphRAG 검색 결과와 LLM 생성 답변을 실시간으로 확인한다. | 필수 |
| FR-014 | 시스템 프롬프트 수정 | LLM에 전달되는 시스템 프롬프트를 UI에서 편집하고 즉시 적용한다. | 필수 |
| FR-015 | 사용량 로그 및 통계 | 일별 챗봇 사용량, 오류율, 검색 미매칭 질문 목록, 평균 응답 시간을 조회한다. | 권장 |
| FR-016 | 구글 SSO 인증 연동 | 관리자 사이트 로그인 시 사내 구글 이메일 연동 기반의 SSO 인증을 적용한다. | 필수 |
| FR-017 | RBAC 기반 권한/메뉴 제어 | 관리자(Admin)와 일반 직원(Employee)으로 역할을 구분하고, 메뉴별 조회/수정 권한을 분리하여 통제한다. | 필수 |

## 5. 비기능 요구사항

| 요구사항 ID | 구분 | 설명 |
| --- | --- | --- |
| NFR-001 | 응답 시간 | 챗봇 답변 최초 청크(First token) 기준 3초 이내 응답을 목표로 한다. |
| NFR-002 | 가용성 | 챗봇 API 서비스 가용성 99.5% 이상을 목표로 한다. |
| NFR-003 | 보안 (인증/인가) | 챗봇 API 인증은 JWT 기반으로 하며, 관리자 서비스는 구글 SSO 연동 및 RBAC 기반 접근 제어를 적용한다. |
| NFR-004 | 확장성 | 향후 탄소 도메인 외 다른 지식 도메인 추가 시 SchemaRegistry만 확장하여 적용 가능해야 한다. |
| NFR-005 | 데이터 무결성 | 인덱싱 실패 시 부분 저장된 데이터를 자동으로 롤백하거나 재시도할 수 있어야 한다. |
| NFR-006 | 유지보수성 | LLM 모델 변경 시 LLMAnswerNode만 수정하면 전체 파이프라인에 영향이 없어야 한다. |

## 6. AI 품질 요구사항

| 요구사항 ID | 항목 | 기준 |
| --- | --- | --- |
| AQ-001 | Grounding (근거 기반 답변) | 모든 답변은 인덱싱된 문서에서 검색된 근거(Evidence)에 기반해야 하며, 할루시네이션 발생 시 "모르는 질문"으로 처리한다. |
| AQ-002 | Recall@K | GraphRAG HybridRetriever의 Top-5 검색 결과 중 정답 관련 청크가 1개 이상 포함되어야 한다. (파일럿 검증 기준) |
| AQ-003 | 도메인 정확성 | 탄소 관련 법규·제도 질문에 대한 답변 정확도를 내부 검수를 통해 80% 이상으로 유지한다. |
