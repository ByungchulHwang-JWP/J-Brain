# 🌿 J-Brain 기반 [탄소 중립 플랫폼] 챗봇 시연 시나리오 완벽 가이드

본 가이드는 J-Brain 시스템을 활용하여 **"탄소 중립 플랫폼"**이라는 신규 도메인의 챗봇을 처음부터 구축하고 실제 시연까지 진행하는 전 과정을 단계별로 상세히 안내하는 **Live Demo 시나리오 매뉴얼**입니다.

이 가이드를 따라 진행하시면 데모 시연을 막힘없이 매끄럽게 진행하실 수 있습니다.

---

## 🚀 1. 신규 프로젝트 등록 (탄소 중립 플랫폼)
> 💡 **기능 소개 (왜 이 작업이 필요한가요?)**  
> J-Brain은 하나의 플랫폼에서 인사, 재무, 그리고 탄소 중립까지 **여러 개의 독립적인 챗봇(도메인)을 동시에 관리**할 수 있는 멀티테넌시(Multi-tenancy) 구조를 지원합니다. 이 단계는 탄소 중립 전용 챗봇을 위한 독립된 워크스페이스(집)를 만드는 과정입니다.

가장 먼저, 우리가 만들 챗봇의 "집"이 될 프로젝트 공간을 생성합니다.

1. 화면 좌측(검은색 사이드바) 메뉴 상단의 **`[1. 프로젝트 준비]`** 메뉴를 클릭합니다.
2. 화면 우측 상단의 **`[+ 신규 프로젝트 생성]`** 버튼을 클릭합니다.
3. 생성 팝업(또는 화면)에서 다음과 같이 입력합니다.
   - **프로젝트 ID:** `Carbon-Zero` (또는 영문/숫자 조합으로 입력)
   - **프로젝트 이름:** `탄소 중립 플랫폼`
   - **설명:** `탄소 배출량 관리 및 중립 목표 달성을 위한 통합 챗봇 시스템`
4. 맨 아래 **`[저장]`** 버튼을 눌러 프로젝트 생성을 완료합니다.
5. 화면 최상단의 **[대상 프로젝트]** 드롭다운 목록을 클릭하여 방금 만든 **`탄소 중립 플랫폼 (Carbon-Zero)`** 로 변경해 줍니다. *(이제부터 모든 작업은 이 프로젝트에 저장됩니다.)*

## 📚 2. 지식 준비 (문서 등록 및 FAQ 추출)
> 💡 **기능 소개 (이 화면은 어떤 역할을 하나요?)**  
> 사내 매뉴얼, 규정집 등 방대한 비정형 문서를 AI가 검색하고 이해할 수 있는 형태(Vector DB)로 변환하여 **챗봇의 뇌에 배경 지식(RAG)을 주입**하는 기능입니다. 더불어 AI가 스스로 문서 안에서 예상 질문과 답변(FAQ)을 뽑아내어 **할루시네이션(환각) 없는 근거 기반의 답변 체계**를 만들어줍니다.

### 2.1) 매뉴얼 문서 등록 및 벡터화
1. 좌측 메뉴에서 **`[2. 지식 준비]`** (또는 Source 관리)를 클릭합니다.
2. 화면 우측 상단의 **`[+ 문서 업로드]`** 버튼을 클릭합니다.
3. 사전에 준비된 **'탄소 중립 플랫폼 통합 소개서 및 매뉴얼'** 파일(PDF, Word 등)을 선택하여 업로드합니다.
4. 업로드된 문서 리스트에서 해당 문서를 찾아 **`[벡터화 (Vectorize) 시작]`** 버튼을 누릅니다.
5. 시스템이 문서를 의미 단위로 쪼개어 AI가 검색할 수 있는 형태(Vector)로 변환합니다. 상태가 **"완료(Completed)"** 로 바뀔 때까지 잠시 대기합니다. *(시연 멘트: "이 과정이 바로 AI에게 기업의 도메인 지식을 학습시키는 RAG의 핵심 단계입니다.")*

### 2.2) Source/FAQ 수집 및 답변 근거 정리 시연
1. 좌측 메뉴에서 **`[FAQ 관리]`** (또는 Source/FAQ 수집 탭)를 클릭합니다.
2. 상단의 **`[AI FAQ 자동 추출]`** 버튼을 클릭합니다.
3. 방금 벡터화를 마친 '탄소 중립 플랫폼 매뉴얼' 문서를 타겟으로 선택하고 **`[추출 시작]`**을 누릅니다.
4. AI가 문서를 스캔하여 사용자 예상 질문과 모범 답변 쌍(Q&A)을 여러 개 생성하여 화면에 띄워줍니다.
   - *(예: Q: "탄소 배출권 거래제(KETS) 참여 대상 기준은 무엇인가요?", A: "최근 3년간 온실가스 배출량 연평균 총량이...")*
5. 추출된 목록 중 시연에 사용할 2~3개의 FAQ 항목을 체크(☑️)한 뒤 **`[답변 근거(Source) 자동 매핑]`** 버튼을 클릭합니다.
6. AI가 해당 답변이 원본 매뉴얼의 **몇 페이지, 어느 단락**에서 나왔는지 근거(Evidence)를 찾아 자동으로 하단에 연결해 주는 화면을 보여줍니다.
7. 매핑이 완료된 FAQ들을 선택하고 **`[FAQ 최종 등록]`**을 눌러 저장합니다. *(시연 멘트: "이렇게 정리된 FAQ는 챗봇이 답변할 때 정확한 문서 출처와 함께 제공되어 할루시네이션(환각)을 완벽히 방지합니다.")*

## 🧠 3. 의도 설계 (Intent Design)
> 💡 **기능 소개 (이 화면은 어떤 역할을 하나요?)**  
> 사용자의 다양한 질문 패턴을 분석하여 '무엇을 원하는지(의도, Intent)'를 정의하고, 도메인에 특화된 동의어(예: KAU = 배출권)를 사전에 학습시키는 **챗봇 지능 설계의 핵심 기능**입니다.

### 3.1) Entity/Synonym (개체/유의어) 사전 학습 시연
1. 좌측 메뉴의 관리 기능 하위에서 **`[Entity/Synonym 관리]`** 메뉴를 클릭합니다.
2. 화면 우측 상단의 **`[+ 신규 Entity 추가]`** 를 클릭합니다.
3. 다음과 같이 입력합니다.
   - **Entity명:** `탄소배출권`
   - **대표어:** `KAU`
   - **유의어:** `배출권, 탄소티켓, 할당배출권`
4. **`[저장]`** 버튼을 클릭합니다. *(시연 멘트: "이러한 동의어 사전을 구축하면, 사용자가 '탄소티켓'이라고 묻든 '배출권'이라고 묻든 AI가 완벽하게 동일한 의도로 알아듣게 됩니다.")*

### 3.2) 문서 기반 Intent 자동 생성 시연
1. 좌측 메뉴에서 **`[3. 의도 설계]`** (또는 Intent 관리)를 클릭합니다.
2. 화면 상단의 **`[AI 자동 생성 (Auto-Generate)]`** 버튼을 클릭합니다.
3. 대상 문서로 방금 업로드한 '탄소 중립 플랫폼 통합 소개서'를 선택하고 **`[생성 시작]`**을 누릅니다.
4. AI가 문서를 분석하여 자동으로 여러 개의 Intent 후보기(예: *탄소 배출량 조회, 인증 절차 안내* 등)를 제안합니다.
5. 마음에 드는 Intent들을 체크(☑️)한 후 **`[선택 항목 등록]`**을 눌러 일괄 저장합니다.

### 3.3) 수동 Intent 직접 등록 시연 (2가지 카테고리)
AI 자동 생성 외에, 관리자가 직접 디테일하게 의도를 통제할 수 있음을 보여줍니다. **`[+ 신규 Intent ->]`** 버튼을 눌러 아래 두 가지를 차례로 등록합니다.

#### ① 화면 이동(Navigate) 유형 Intent 등록
- **Intent 이름:** `탄소 배출량 대시보드 이동`
- **Category:** `navigate` (화면 이동)
- **Status:** `active`
- **Action 연결:** `Action 선택 전` (나중에 연결합니다)
- **예시 질문 등록:**
  - `우리 회사 이번 달 탄소 배출량 얼마야?`
  - `배출량 대시보드 화면 띄워줘`
  - `탄소 현황판 보여줄래`
- **`[저장]`** 클릭

#### ② 외부 데이터 조회(API) 유형 Intent 등록
- **Intent 이름:** `실시간 탄소 배출권 시세 조회`
- **Category:** `query` (데이터 조회/API)
- **Status:** `active`
- **Action 연결:** `Action 선택 전`
- **예시 질문 등록:**
  - `오늘 탄소 배출권 얼마야?`
  - `KAU 실시간 거래 가격 알려줘`
  - `현재 탄소 시세 조회해 줘`
- **`[저장]`** 클릭

## 🔗 4. 실행 연결 (Action Mapping)
> 💡 **기능 소개 (이 화면은 어떤 역할을 하나요?)**  
> 파악된 사용자 의도(Intent)에 따라 특정 화면으로 이동시킬지(Navigate), 외부 데이터를 불러올지(API), 혹은 단순히 답변만 할지(Message) **챗봇의 실제 행동(Action)을 짝지어주는 매핑(Mapping) 공간**입니다.

1. 좌측 메뉴에서 **`[4. 실행 연결]`** 을 클릭합니다.
2. 우측 상단의 **`[Action 빠른 등록]`**을 눌러 두 가지 Action을 만듭니다.
   - **Action 1:** 이름: `배출량 대시보드 이동`, 유형: `NAVIGATE`, 메뉴명: `탄소 대시보드`, URL: `/carbon/dashboard`
   - **Action 2:** 이름: `배출권 시세 API 조회`, 유형: `API_CALL`, API 엔드포인트: `/api/carbon-price/current`
3. 미연결 Intent 목록에서 방금 만든 `탄소 배출량 대시보드 이동` Intent의 **`[열기]`** 버튼을 클릭합니다.
4. Action 연결 드롭다운에서 방금 만든 **`[배출량 대시보드 이동]`** Action을 찾아 연결 후 **`[저장]`** 합니다.
5. 동일한 방법으로 `실시간 탄소 배출권 시세 조회` Intent에도 **`[배출권 시세 API 조회]`** Action을 연결해 줍니다.

## 📦 5. Pack 검증 및 빌드
> 💡 **기능 소개 (이 화면은 어떤 역할을 하나요?)**  
> 앞서 정의한 지식, 의도, 액션들을 모두 모아 하나의 **'설치형 두뇌 패키지(Pack)'로 압축 파일화(빌드)** 하고, 배포 전에 오류나 연결 누락이 없는지 무결성을 검증하는 형상 관리 기능입니다.

### 5.1) Pack 검증 (사전 오류 체크)
1. 좌측 메뉴에서 **`[Pack 검증]`** 탭을 클릭합니다.
2. 현재 설계된 Intent와 Action 간에 연결 누락이 없는지, 중복된 예시 문장이 없는지 시스템이 스캔합니다.
3. 화면에 나타난 **`[무결성 검사 실행]`** 버튼을 클릭하여 모든 항목이 초록색 'Pass' 상태가 되는 것을 보여줍니다. *(시연 멘트: "배포 전 발생할 수 있는 휴먼 에러를 시스템이 완벽하게 차단해 주는 안전장치입니다.")*

### 5.2) Pack Builder (빌드 및 패키징)
1. 좌측 메뉴에서 **`[Pack Builder]`** 를 클릭합니다.
2. 화면에 오늘 작업한 Intent, Entity, 문서 건수가 올바르게 표시되는지 요약 정보를 확인합니다.
3. 우측 하단의 **`[Pack 빌드]`** (또는 Export / ZIP 생성) 버튼을 클릭합니다.
4. 버전 번호(예: `v0.1.0` -> `v0.2.0`)가 자동으로 증가하며 **`Carbon-Zero-intent-pack-v0.2.0`** 파일이 성공적으로 생성되었음을 확인합니다.

### 5.3) Pack Repository (저장소 확인)
1. 좌측 메뉴에서 **`[Pack Repository]`** 를 클릭합니다.
2. 방금 생성된 패키지가 물리적으로 안전하게 보관되어 있는 리스트를 확인합니다. *(시연 멘트: "언제든지 이전 버전의 두뇌로 롤백(Rollback)할 수 있도록 버전 관리 이력이 자동으로 저장됩니다.")*

## 📤 6. 배포 및 운영 개선 (Deploy & QA)
> 💡 **기능 소개 (이 화면은 어떤 역할을 하나요?)**  
> 완성된 두뇌(Pack)를 **실제 운영 서버(Runtime)에 원클릭으로 무중단 배포**하고, 배포된 챗봇 모델이 사용자 질문을 어떻게 추론하는지 점수(Score)와 함께 화이트박스 형태로 시뮬레이션 해보는 기능입니다.

### 6.1) 버전/배포 관리 (Active Pack 적용)
1. 좌측 메뉴에서 **`[버전/배포 관리]`** 메뉴로 들어갑니다.
2. 방금 빌드된 최신 버전의 Pack을 리스트에서 찾습니다.
3. 우측의 **`[실서버 배포 (Activate)]`** 버튼을 클릭합니다.
4. "성공적으로 배포되었습니다." 알림을 확인합니다. 이제 챗봇이 새로운 지식과 로직을 장착했습니다!

### 6.2) Runtime QA 대화 테스트
1. 좌측 메뉴에서 **`[Intent Runtime 대화 테스트]`** 메뉴를 클릭합니다.
2. 하단의 테스트 모드가 방금 배포한 최신 버전(Active Pack)으로 되어있는지 확인합니다.
3. 하단 검색창에 `"오늘 탄소 티켓 시세 알려줄래?"` 라고 일부러 유의어(동의어)를 섞어서 입력하고 엔터를 칩니다.
4. QA 결과 화면에 **Top Intent (실시간 탄소 배출권 시세 조회)**, **스코어 (높은 매칭 점수)**, **연결된 Action**이 상세하게 출력되는 과정을 보여줍니다. *(시연 멘트: "단순히 챗봇이 텍스트만 뱉어내는 것이 아니라, 동의어 사전을 거쳐 내부적으로 어떤 AI 추론 과정을 통해 이 의도를 확신했는지 투명하게 모니터링할 수 있습니다.")*

## 🎯 7. 챗봇 시연 (Live Chat Demo)
> 💡 **기능 소개**  
> 지금까지 설정한 모든 백엔드 로직이 실제 사용자 UI(웹사이트 우측 하단의 채팅 위젯)에서 어떻게 동작하는지 직관적으로 보여주는 최종 결과물 화면입니다.

이제 우측 하단에 떠 있는 **[J-Brain AI Assistant (채팅 위젯)]**을 열고 실제로 대화하며 완벽하게 동작하는 모습을 보여줍니다. *(시연 시 상단의 프로젝트가 '탄소 중립 플랫폼'으로 선택되어 있는지 확인하세요!)*

### 📝 7.1 시연 질의 준비 (대본)

시연 효과를 극대화하기 위해 다음 세 가지 시나리오를 순서대로 질의합니다.

#### 💬 시나리오 A: 화면 이동 (Navigation Action 테스트)
> **시연자 입력:** `"이번 달 우리 회사 탄소 배출 현황 좀 띄워줄래?"`  
> **기대 결과:**
