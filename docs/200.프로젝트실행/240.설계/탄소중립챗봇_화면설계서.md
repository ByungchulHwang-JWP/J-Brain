## 3. 화면 상세 설계

### 3.1 `UI-FO-001` : 챗봇 위젯 메인 (Front-Office)

**화면 설명**: 
기존 `ktnetzero.kt.co.kr` 웹사이트 하단에 플로팅 버튼으로 노출되며, 클릭 시 대화창이 열립니다.

**주요 UI 요소**:
- **상단 헤더**: "KT Net Zero AI 어시스턴트" 타이틀, [초기화(새 대화)] 버튼, [닫기] 버튼
- **대화 영역**:
  - 사용자 발화 말풍선 (우측 정렬)
  - 챗봇 응답 말풍선 (좌측 정렬)
  - **출처(Evidence) 표시**: 챗봇 답변 하단에 `[참고 문서: 배출권거래제_지침.pdf (매칭률 95%)]` 형태의 클릭 가능한 칩(Chip) 표시
  - 로깅 애니메이션 (스트리밍 타이핑 효과)
- **입력 영역**: 텍스트 입력창 (멀티라인 지원), [전송] 버튼 (아이콘)

**동작 흐름**:
1. 사용자가 질문 입력 후 Enter 또는 전송 버튼 클릭
2. 로딩 인디케이터(...) 표시 후 스트리밍 형태로 답변 출력
3. 출처 칩 클릭 시 문서의 원본 청크(텍스트 파편) 내용 모달 노출

---

### 3.2 `UI-BO-001` : 통합 로그인 (SSO)

**화면 설명**: 
관리자/직원이 시스템에 접속하기 위한 첫 관문입니다. 별도 ID/PW 입력 없이 사내 구글 계정으로 연동됩니다.

**주요 UI 요소**:
- 중앙 로그인 박스
- 서비스 로고: "KT Net Zero Admin"
- 버튼: **[Google 계정으로 로그인]** 버튼 1개만 제공
- 하단: 접근 권한 신청 안내 문구 ("권한이 없는 경우 시스템 관리자에게 문의하세요.")

---

### 3.3 `UI-BO-002` : 대시보드

**화면 설명**: 
로그인 후 처음 보여지는 랜딩 페이지로, 챗봇 운영 현황을 한눈에 파악합니다.

**주요 UI 요소 (위젯 형태 배치)**:
- **상단 요약 카드**: 일일 사용자 수, 총 질문 수, 인덱싱된 문서 수, 평균 응답 시간(ms)
- **차트 영역 (좌측)**: 최근 7일간 토큰 사용량 추이 (막대/꺾은선 그래프)
- **차트 영역 (우측)**: 가장 많이 질문된 키워드 (Word Cloud)
- **하단 테이블**: 최근 발생한 에러(답변 실패, 인덱싱 실패 등) 로그 요약

---

### 3.4 `UI-BO-003` : 지식(Source) 관리

**화면 설명**: 
GraphRAG의 근간이 되는 원본 문서를 등록하고 벡터화(인덱싱) 작업을 수행합니다.

**주요 UI 요소**:
- **상단 검색 바**: 카테고리 필터(법령, 가이드 등), 상태 필터, 검색어 입력
- **버튼**: [문서 업로드] (클릭 시 파일 선택 및 설명 입력 모달 팝업)
- **데이터 그리드 (테이블)**:
  - 컬럼: ID, 파일명, 카테고리, 상태(UPLOADED, PROCESSING, COMPLETED), 등록일시, 액션
  - 액션: [인덱싱 실행] 버튼, [삭제] 버튼
- **작업 모니터링 영역**: 진행 중인 `index_jobs`의 진행률 바(Progress Bar) 표시

---

### 3.5 `UI-BO-004` : 챗봇 테스트 및 프롬프트 관리

**화면 설명**: 
실제 사용자에게 반영하기 전, 관리자가 답변 품질을 검수하고 프롬프트를 조정하는 샌드박스 화면입니다.

**화면 분할 (Split View)**:
- **좌측 패널 (시스템 프롬프트 편집기)**:
  - 텍스트 에어리어: 현재 적용된 `system_prompts` 표시
  - 하단 [저장 및 즉시 적용] 버튼
- **우측 패널 (테스트 챗봇)**:
  - FO 화면과 동일한 형태의 챗봇 대화창 제공
  - 부가 기능: 각 답변마다 LLM이 참고한 `Graph Relation` 및 `Vector Score` 상세 정보 보기(디버그 모드) 버튼 제공

---

### 3.6 `UI-BO-005` : 권한 및 메뉴 관리 (RBAC)

**화면 설명**: 
직원별 권한 그룹을 할당하고, 각 그룹(Role)이 접근할 수 있는 메뉴를 통제합니다.

**주요 UI 요소**:
- **상단 탭**: [계정 목록] / [메뉴-권한 매핑]
- **계정 목록 탭**:
  - 가입된 구글 이메일, 이름, 부여된 Role(`ROLE_ADMIN`, `ROLE_EMPLOYEE`) 표기. Role 변경 드롭다운 제공
- **메뉴-권한 매핑 탭**:
  - 좌측: Role 목록 (관리자, 직원) 선택
  - 우측: 해당 Role의 메뉴 트리 권한 체크박스 
    - 예: `지식 관리` 메뉴 (조회 [v] / 수정 [v])
    - 예: `대시보드` 메뉴 (조회 [v] / 수정 [ ])
  - 하단 [권한 저장] 버튼
