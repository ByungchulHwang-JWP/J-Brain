## 3. 상세 기능 목록 (Feature List)

### 3.1 로그인 및 인증 (Auth)
| 기능 ID | 대분류 | 중분류 | 기능명 | 상세 설명 | 비고 |
| --- | --- | --- | --- | --- | --- |
| `BO-001` | 인증 | 로그인 | 구글 SSO 연동 로그인 | 사내 구글 이메일을 연동하여 별도 패스워드 없이 OAuth2 로그인 처리 | |
| `BO-002` | 인증 | 인가 | RBAC 기반 라우팅 | 발급된 JWT 토큰의 `role_id`를 검사하여 접속 불가한 메뉴는 GNB에서 숨김 및 접근 차단 | |

### 3.2 대시보드 (Dashboard)
| 기능 ID | 대분류 | 중분류 | 기능명 | 상세 설명 | 비고 |
| --- | --- | --- | --- | --- | --- |
| `BO-010` | 대시보드 | 통계 | 일간/주간 요약 위젯 | 총 방문자 수, 총 질문 수, 인덱싱 완료 문서 수 등 핵심 KPI 요약 카드 노출 | |
| `BO-011` | 대시보드 | 통계 | 토큰 사용 추이 차트 | OpenAI API 호출에 따른 일일 토큰(비용) 사용량 추이를 꺾은선 차트로 제공 | |
| `BO-012` | 대시보드 | 통계 | 인기 키워드 | 최근 7일간 사용자들이 가장 많이 언급한 명사 위주의 Word Cloud 제공 | |
| `BO-013` | 대시보드 | 로그 | 시스템 오류 현황 | 답변 생성 실패, 인덱싱 실패 등 최근 발생한 시스템 에러 로그 요약 테이블 노출 | |

### 3.3 지식 관리 (Knowledge Base)
| 기능 ID | 대분류 | 중분류 | 기능명 | 상세 설명 | 비고 |
| --- | --- | --- | --- | --- | --- |
| `BO-020` | 지식관리 | 문서(Source) | 지식 문서 목록 조회 | 등록된 문서(PDF, TXT)의 파일명, 카테고리, 등록일, 인덱싱 상태 목록 조회 | 페이징/검색 포함 |
| `BO-021` | 지식관리 | 문서(Source) | 문서 업로드 및 등록 | 신규 파일을 드래그 앤 드롭으로 업로드하고 분류 카테고리와 함께 DB에 저장 | |
| `BO-022` | 지식관리 | 인덱싱(Index) | **비동기 인덱싱 실행** | 특정 문서를 선택하여 GraphRAG 파이프라인(청킹/임베딩/추출) 백그라운드 작업 시작 | 핵심 기능 |
| `BO-023` | 지식관리 | 인덱싱(Index) | 진행 상태 모니터링 | 현재 진행 중인 인덱싱 작업(`index_jobs`)의 % 진행률과 성공/실패 여부 실시간 조회 | Polling 적용 |
| `BO-024` | 지식관리 | 미리보기 | 추출된 엔티티/그래프 조회 | 특정 문서에서 추출된 Chunk 데이터, Entity 노드, Relation 엣지 목록 팝업 미리보기 | |
| `BO-025` | 지식관리 | 문서(Source) | 지식 문서 삭제 | 문서를 삭제하고 해당 문서에서 파생된 모든 Chunk, Entity, Relation 데이터를 연쇄 삭제(Cascade) | |

### 3.4 챗봇 테스트 및 프롬프트 관리 (Prompt & Test)
| 기능 ID | 대분류 | 중분류 | 기능명 | 상세 설명 | 비고 |
| --- | --- | --- | --- | --- | --- |
| `BO-030` | 프롬프트 | 테스트 | 샌드박스 챗봇 | 관리자 화면 내에 사용자(FO)와 동일한 챗봇 창을 띄워 응답 품질 검증 테스트 진행 | |
| `BO-031` | 프롬프트 | 튜닝 | 시스템 프롬프트 조회/수정 | LLM의 답변 어조, 제약 사항을 제어하는 `system_prompts` 데이터를 편집기에서 수정 및 즉시 반영 | |
| `BO-032` | 프롬프트 | 디버깅 | **추적(Trace) 도구 제공** | 샌드박스 챗봇에서 질문 시, LLM이 참조한 DB 테이블의 Vector 스코어 및 텍스트 청크 원본을 조회 | |

### 3.5 권한 및 메뉴 관리 (RBAC)
| 기능 ID | 대분류 | 중분류 | 기능명 | 상세 설명 | 비고 |
| --- | --- | --- | --- | --- | --- |
| `BO-040` | 권한관리 | 역할(Role) | 시스템 권한 목록 조회 | 등록된 권한 그룹(`sys_roles`) 및 그룹별 상세 설명 조회 | |
| `BO-041` | 권한관리 | 매핑(Mapping) | 사용자-권한 매핑 | 구글 SSO로 가입된 사용자 목록(`admin_users`)을 조회하고 특정 사용자에게 관리자/직원 권한 부여 | |
| `BO-042` | 권한관리 | 매핑(Mapping) | 권한-메뉴 접근 제어 설정 | 권한별로 좌측 메뉴(`sys_menus`) 트리를 조회(`can_read`) / 수정(`can_write`) 가능 여부 체크박스 매핑 | |
